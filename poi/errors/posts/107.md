## 什么是Markdown？

Markdown是一种轻量级标记语言，让你可以使用纯文本格式编写文档，然后转换成有效的HTML。

## 基本语法

### 文本格式

- **粗体文本**使用双星号
- *斜体文本*使用单星号
- ~~删除线~~使用双波浪号

### 代码

行内代码：`console.log('Hello')`

代码块：

```javascript
function greet(name) {
    return `Hello, ${name}!`;
}
```

### 列表

1. 第一项
2. 第二项
3. 第三项

### 引用

> Markdown让写作回归本质，专注于内容而非排版。

现在你可以在博客中使用Markdown格式编写文章了！只需在文章数据中设置 `content_type: "md"`，并创建对应的 `.md` 文件即可。
